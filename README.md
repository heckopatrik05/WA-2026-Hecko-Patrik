# WA-2026-Hecko-Patrik

## Checklist: Semestrální projekt

### 1. Základní koncept a vzhled
- [ ] **Výběr tématu:** Zvolit si vlastní unikátní téma/entitu (nesmí to být knihy).
- [ ] **Struktura DB:** Navrhnout pro vybranou entitu odpovídající databázovou strukturu a tabulku.
- [ ] **CRUD:*** CRUD operace pro vlastní DB strukturu
- [ ] **Logo:** Vymyslet a vytvořit vlastní logo pro webovou aplikaci.
- [ ] **Design:** Odvodit celkový design a barevnost aplikace od navrženého loga.

### 2. Uživatelské profily
- [ ] **CRUD profilu:** Implementovat operace pro zobrazení a úpravu uživatelského profilu.
- [ ] **Oprávnění pro mazání:** Zajistit, aby smazání uživatele mohl provést **pouze** administrátor.

### 3. Komentářový systém k vaší entitě
- [ ] **Zobrazení a přidávání:** Zprovoznit formulář pro vkládání a výpis komentářů (ideálně na stránce detailu konkrétního záznamu).
- [ ] **CRUD operace:** Implementovat možnost komentáře nejen tvořit, ale i upravovat a mazat.
- [ ] **Přístupová práva:** Vymyslet a naprogramovat jasná pravidla pro manipulaci s komentáři (např. kdo je může vidět, kdo upravovat vlastní, kdo mazat cizí atd.).

### 4. Návaznost na cvičení
- [ ] **Základní funkcionalita:** Mít plně funkční CRUD nad hlavní entitou, včetně funkčního přihlašování, autentizace a autorizace (vychází z cvičení).
- [ ] **Samostatné úkoly:** Mít implementované všechny dílčí samostatné úkoly, které plynule navazovaly na probíranou látku během semestru (viz https://github.com/zizanek/WA-2026-Zizka-Tomas/issues/30).

### 🌟 Extra (Kladně hodnoceno)
- [ ] **Vlastní invence:** Přinést něco navíc! Libovolná smysluplná funkce, vylepšení kódu nebo designu nad rámec tohoto minimálního zadání.
